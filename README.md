# Netflix Clone 🎬

A Netflix-inspired website built using HTML and CSS. This project recreates the look and feel of a Netflix-style streaming platform and was created to practice frontend web development.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Netflix-inspired user interface
* Navigation bar
* Hero/banner section
* Movie and content sections
* Custom styling using CSS
* Asset-based images and content

## 📁 Project Structure

```text
netflix-clone/
├── index.html
├── style.css
└── asset/
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. The Netflix clone will run locally.
